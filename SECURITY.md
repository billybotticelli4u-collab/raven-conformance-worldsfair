# Security

This is a hackathon demonstration of a conformance runner against Raven-owned fixtures. It is not a security product and issues no safety verdicts.

Report a defect or a security concern by opening an issue in this repository, or through the contact paths on ravenattest.com. Please include the exact commit and the command that reproduces the behaviour. Reports that show a divergence between a target's claimed profile and its observed behaviour are the point of the tool and are welcome.
